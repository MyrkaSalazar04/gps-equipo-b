Análisis del Sistema de Control Escolar de Servicio Social y Residencia Profesional

Integrante: Myrka Salazar
Modalidad: Individual

Hipótesis inicial (Práctica 1)
Observando únicamente la estructura de carpetas y archivos (sin abrir código):

¿Qué creo que hace el sistema?
Es una plataforma escolar para llevar el control y seguimiento de los trámites de Servicio Social y Residencia Profesional.
Sirve para gestionar todo el proceso: desde el registro del alumno y la entrega de planes de trabajo, hasta la revisión de reportes y
la emisión de la liberación final.

¿Para quién está hecho?
Está diseñado para tres tipos de usuarios:
- Alumnos: Para subir sus documentos, reportes de avances y revisar el estado de su trámite.
- Coordinadores / Vinculación: Para revisar solicitudes, validar expedientes y asignar asesores.
- Asesores (Internos y Externos): Para evaluar el desempeño de los estudiantes y calificar sus entregas.

¿Con qué tecnología está construido?
Es una app web clásica. Usa HTML, CSS y JavaScript para la interfaz y formularios, y por la estructura de carpetas 
parece llevar un backend en PHP con MySQL para manejar los usuarios, reportes y la base de datos.

¿Qué tan grande parece ser?
Es un proyecto de tamaño mediano, con alrededor de 10 a 20 carpetas y archivos principales en la raíz. 
Es una estructura web monolítica bien organizada por módulos (estilos, imágenes, scripts y vistas) para cubrir 
el flujo institucional sin llegar a ser extremadamente compleja.
